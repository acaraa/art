# @noah.aiart 영상 제작 스튜디오

@noah.aiart의 영상 작업 저장소입니다. 영상 하나에 폴더 하나를 쓰고, 각 폴더에는 완성 영상과 그 영상을 다시 만드는 소스가 함께 들어 있습니다.

## 영상

| 폴더 | 내용 | 길이 | 유튜브 |
|---|---|---|---|
| [`ai-week-1029/`](ai-week-1029/) | AI 위클리 · 10월 마지막 주 (Broadcast News Package 스타일) | 68초 | [보기](https://youtu.be/V8rwZ4BBMQk) |
| [`sudoku-ai-1030/`](sudoku-ai-1030/) | AI는 스도쿠를 몇 초 만에 풀까 (ASCII / CRT Terminal 스타일, 세로 쇼츠) | 39초 | 아직 올리지 않음 |

## 시작하기

```sh
sh tools/setup.sh      # 도구 설치: lemo-opuscar, Craft 앱 명령줄 도구, 글꼴
. tools/env.sh         # 경로 설정
```

작업 규칙(브랜드, 폴더 구성, 검수 항목)은 [`CLAUDE.md`](CLAUDE.md)에 있습니다.

## 사용자 컴퓨터에 설치할 앱

화면이 있는 데스크톱 앱은 각자 컴퓨터에 설치합니다. 각 저장소의 Releases 페이지에서 macOS, Windows, Linux용 설치 파일을 받을 수 있습니다.

| 앱 | 용도 |
|---|---|
| [craft-launcher](https://github.com/storytold/craft-launcher) | Craft 앱들을 한 번에 설치·관리 (먼저 설치 권장) |
| [ArtCraft](https://github.com/storytold/artcraft) | AI 이미지·영상 생성을 화면에서 조절하는 작업 도구 |
| [FilmCraft](https://github.com/storytold/filmcraft) | 영상 편집 |
| [EffectCraft](https://github.com/storytold/effectcraft) | 모션그래픽 |
| [SoundCraft](https://github.com/storytold/soundcraft) | 오디오 편집·믹싱 |
| [PhotoCraft](https://github.com/storytold/photocraft) · [LightCraft](https://github.com/storytold/lightcraft) | 사진 편집 · 보정 |
| [VectorCraft](https://github.com/storytold/vectorcraft) · [DesignCraft](https://github.com/storytold/designcraft) | 벡터 그래픽 · 레이아웃 디자인 |
| [DeckCraft](https://github.com/storytold/deckcraft) | 발표 자료 |
| [craft-fonts](https://github.com/storytold/craft-fonts) | Craft 앱용 글꼴 모음 (한국어 포함) |
